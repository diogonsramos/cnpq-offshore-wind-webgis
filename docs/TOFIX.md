A landing page apresenta um bom nível de organização visual e já comunica claramente o objetivo do projeto, com destaque para o título, indicadores técnicos e caminhos para acesso às ferramentas. No entanto, existem alguns pontos importantes de usabilidade, experiência do usuário e boas práticas de interfaces que precisam ser ajustados para tornar a página mais profissional, navegável e aderente a padrões modernos. No futuro, os experimentos climáticos serão ajustado por modelo (WRF, MPAS) x experimento (ERA5, CMIP6 HIST, CMIP6 SSP2-4.5 e CMIP6 SSP5-8.5) x período (histórico, presente, futuro) x variável x altura x batimetria x distância náutica. Estes dados estão em processamento local neste momento.

Problemas críticos (corrigir antes do merge)
• Não há barra de rolagem funcional na página. Isso impede a navegação completa pelo conteúdo e compromete totalmente a usabilidade.
• Verificar se há algum overflow hidden indevido no body ou containers principais.
• Garantir que a página permita scroll vertical em todas as resoluções.
• Validar comportamento em diferentes tamanhos de tela (desktop, notebook e mobile).

Experiência do usuário e navegação
• A página não possui menu de navegação entre seções (ex: Metodologia, Cenários, Equipe, Publicações).
• Recomenda-se adicionar um menu fixo (navbar) ou âncoras para facilitar navegação.
• Incluir indicador visual de seção ativa ao rolar a página.
• Considerar adicionar botão “voltar ao topo” para páginas longas.
• Os botões principais estão bem posicionados, mas poderiam ter maior contraste ou destaque visual.

Hierarquia de informação
• A hierarquia geral está boa, mas alguns blocos poderiam ter melhor separação visual.
• Melhorar espaçamentos verticais entre seções para evitar sensação de conteúdo “compactado”.
• Os títulos de seção (ex: Metodologia, Interface, Equipe) poderiam ter maior destaque visual em relação ao conteúdo.
• Padronizar uso de textos introdutórios em cada seção para melhorar fluidez de leitura.

Design e consistência visual
• Os cards utilizados são consistentes, mas poderiam ter pequenas melhorias:
o Ajustar sombras e bordas para maior profundidade visual.
o Garantir alinhamento consistente entre todos os elementos.
• Padronizar cores dos badges (ex: coordenador, pesquisador líder, pesquisador).
• Garantir consistência nos estilos de ícones (alguns parecem diferentes em peso visual).
• Avaliar contraste de cores para acessibilidade (especialmente textos menores).

Tipografia e legibilidade
• Alguns textos estão relativamente densos, principalmente no bloco “Resumo Técnico”.
• Recomenda-se aumentar espaçamento de linha (line-height).
• Avaliar redução de largura de parágrafos para melhorar leitura.
• Melhorar diferenciação entre título, subtítulo e corpo de texto.

Conteúdo e clareza
• O conteúdo técnico está bem detalhado, porém pode estar denso para usuários não técnicos.
• Considerar adicionar uma seção inicial “Sobre o projeto” com linguagem mais acessível.
• Incluir um resumo executivo mais direto no topo da página.
• Algumas descrições poderiam ser levemente simplificadas ou segmentadas em bullets.

• Sugestões:
o Padronizar textos (alguns mais detalhados que outros).
o Incluir um pequeno tooltip ou “saiba mais” para termos técnicos.
o Melhorar diferenciação visual entre cenários históricos e futuros.
